# Account Authentication Discovery

Use this skill to discover Account.js.gripe authentication requirements without crawling protected account pages.

The account service is private. Agents may read `auth.md`, OAuth metadata, the API catalog, and the OpenAPI description. Protected user data requires an authorized account session or administrator-created API client.

Primary resources:
- https://account.js.gripe/auth.md
- https://account.js.gripe/.well-known/oauth-protected-resource
- https://account.js.gripe/.well-known/oauth-authorization-server
- https://account.js.gripe/openapi.json
